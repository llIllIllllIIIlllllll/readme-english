언어 습득의 열쇠는 충분한 양의 이해 가능한 입력(Comprehensible Input)입니다. 어려운 보안·시스템 전문 용어부터 던지지 않고, 쉬운 기본 문형(Easy, i)으로 핵심 어휘를 익힌 뒤 실전 README 문장(Mid, i+1)으로 부드럽게 올라갑니다. 듣기(1.0x / 0.8x / 0.65x) → 문맥 파악(단어 힌트) → 가벼운 이해 확인 → (선택) 따라 말하기의 순서로 학습하세요.
